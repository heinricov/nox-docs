---
title: "Custom Header & Footer"
description: "Ganti header dan footer bawaan NoxLayout lewat props navheader dan navfooter"
---

`NoxLayout` menyediakan dua props untuk menyesuaikan header dan footer tanpa mengubah struktur kerangka:

- **`navheader`** — menerima `ReactNode`; default-nya komponen `SiteHeader` dari `default-header.tsx`
- **`navfooter`** — menerima `ReactNode`; default-nya komponen `AppFooter` dari `default-footer.tsx`

Selama props tidak diberikan, `NoxLayout` otomatis memakai komponen default-nya masing-masing.

## Custom Header

Buat komponen header Anda sendiri, lalu kirim lewat prop `navheader`. Header default menggunakan `useSidebar` dari `@nox/core/components/sidebar`, jadi Anda bisa memakainya juga untuk tombol toggle sidebar:

<CodeBlock filename="components/site-header.tsx">
```tsx
"use client"

import Link from "next/link"
import { usePathname } from "next/navigation"
import { PanelLeftIcon } from "lucide-react"

import { Button } from "@nox/core/components/button"
import { useSidebar } from "@nox/core/components/sidebar"

export function SiteHeader() {
  const { toggleSidebar } = useSidebar()
  const pathname = usePathname()

  return (
    <header className="sticky top-0 z-50 flex h-16 w-full items-center border-b bg-background px-4">
      <Button
        className="shrink-0 lg:hidden"
        variant="ghost"
        size="icon"
        aria-label="Toggle sidebar"
        onClick={toggleSidebar}
      >
        <PanelLeftIcon />
      </Button>
      <span className="ml-4 text-sm font-semibold">
        {pathname === "/" ? "Home" : "Docs"}
      </span>
    </header>
  )
}
````
</CodeBlock>

## Custom Footer

Buat komponen footer sendiri, lalu kirim lewat prop `navfooter`:

<CodeBlock filename="components/site-footer.tsx">
```tsx
export function SiteFooter() {
  return (
    <footer className="border-t bg-background px-4 py-6">
      <p className="text-center text-sm text-muted-foreground">
        &copy; {new Date().getFullYear()} My Company
      </p>
    </footer>
  )
}
````
</CodeBlock>

## Pakai di NoxLayout

`navheader` dan `navfooter` diganti di tempat pemasangan `NoxLayout`:

<CodeBlock filename="app/layout.tsx">
```tsx
import { NoxLayout } from "@nox/layouts"
import { sidebarMenu } from "@/lib/sidebar-menu"
import { SiteHeader } from "@/components/site-header"
import { SiteFooter } from "@/components/site-footer"

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en">
      <body>
        <NoxLayout
          targetDir={["/docs"]}
          menu={sidebarMenu}
          navheader={<SiteHeader />}
          navfooter={<SiteFooter />}
        >
          {children}
        </NoxLayout>
      </body>
    </html>
  )
}
````
</CodeBlock>

## Menyembunyikan Header atau Footer

Berikan `navheader={null}` atau `navfooter={null}` bila ingin menghapus bagian tersebut sepenuhnya:

<CodeBlock filename="app/layout.tsx">
```tsx
<NoxLayout targetDir={["/docs"]} menu={sidebarMenu} navheader={null}>
  {children}
</NoxLayout>
````
</CodeBlock>
