Anda bisa langsung menggunakan NoxKit dengan Templates yang disediakan.

Ada dua Templates yang disediakan oleh NoxKit:

- Next.Js App Router
- Shadcn UI Template

## Instalasi noxkit dengan Templates

- Instalasi noxkit dengan Templates:

<PackageManagerTabs>create-app-noxkit@latest</PackageManagerTabs>

- Jalankan printah install noxkit, dengan hasil seperti ini:

## CLI Commands

- anda bisa menggunakan perintah berikut untuk membuat proyek Anda:

<PackageManagerTabs>
  {`create-app-noxkit@latest --template nextjskit`}
</PackageManagerTabs>

printah ini akan membuat proyek Anda dengan template Next.Js App Router.

<PackageManagerTabs>
  {`create-app-noxkit@latest --template shadcnkit --preset b1tMcUbQm`}
</PackageManagerTabs>

printah ini akan membuat proyek Anda dengan template Next.Js App Router + Shadcn UI Template.
