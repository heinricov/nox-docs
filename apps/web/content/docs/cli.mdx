# CLI

Squadra menyediakan CLI untuk membantu _scaffolding_ proyek baru dan tugas pengembangan sehari-hari.

## Instalasi

```bash
pnpm add -g @squadra/cli
```

## Perintah Dasar

| Perintah          | Deskripsi                               |
| ----------------- | --------------------------------------- |
| `squadra init`    | Inisialisasi proyek baru                |
| `squadra add`     | Tambahkan komponen ke proyek            |
| `squadra dev`     | Jalankan development server             |
| `squadra build`   | Build proyek untuk production           |
| `squadra help`    | Tampilkan bantuan perintah              |

## Contoh Penggunaan

### Membuat Proyek Baru

```bash
squadra init my-project
cd my-project
```

### Menambahkan Komponen

```bash
squadra add button
squadra add card --variant outline
```

Perintah di atas akan menyalin komponen ke folder `components/ui/`.

## Opsi Global

- `--yes` — lewati semua prompt konfirmasi
- `--dry-run` — tampilkan aksi tanpa menjalankan
- `--help` — tampilkan bantuan

> **Tip:** gunakan `squadra add --help` untuk melihat daftar opsi lengkap.
