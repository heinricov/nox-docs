## Instalasi NoxKit Manual Project

Ada dua cara untuk menginstal noxkit:

- Memulai dengan membuat proyek baru [Next.js](https://nextjs.org/docs/app-router) dengan menggunakan `create-next-app`
- Memulai melalui create proyect di Shadcn UI [Shadcn UI Create](https://ui.shadcn.com/create).

Anda bisa mengunjungi dokumentasi lengkap [Shadcn UI Create](https://ui.shadcn.com/create) untuk memahami lebih lanjut tentang cara menggunakan Shadcn UI Create dan dokumentasi [Next.js](https://nextjs.org/docs/app-router) untuk memahami lebih lanjut tentang cara menggunakan Next.js App Router.

## Setup

### Tambahkan paket ke transpilePackages

Karena `noxkit` didistribusikan sebagai source TypeScript, tambahkan ke `transpilePackages` di `next.config.ts`:

<CodeBlock filename="next.config.ts">
```ts
import type { NextConfig } from "next"

const nextConfig: NextConfig = {
transpilePackages: ["noxkit"],
}

export default nextConfig
```
</CodeBlock>

### Update globals.css

Pastikan `app/globals.css` mengimpor Tailwind dan dependensinya:

<CodeBlock filename="app/globals.css">

```css
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "noxkit/globals.css";
```

</CodeBlock>

`NoxLayout` mengimpor tema `noxkit` secara otomatis, jadi Anda tidak perlu menambahkan import CSS noxkit secara manual.

### Edit root layout

Ganti isi `app/layout.tsx` dengan `NoxLayout`, dan definisikan menu sidebar bertipe `NoxSidebarMenu`:

<TabsSection>
  <TabsContent value="Next.js">
    
    <CodeBlock filename="app/layout.tsx">
      ```tsx
      import type { ReactNode } from "react"
      import type { Metadata } from "next"
      import { Geist, Geist_Mono } from "next/font/google"
      import "./globals.css"

      import { NoxLayout } from "noxkit"
      import type { NoxSidebarMenu } from "noxkit"

      const geistSans = Geist({
      variable: "--font-geist-sans",
      subsets: ["latin"],
      })

      const geistMono = Geist_Mono({
      variable: "--font-geist-mono",
      subsets: ["latin"],
      })

      export const metadata: Metadata = {
        title: "Create Next App",
        description: "Generated by create next app",
      }

      export const sidebarMenu: NoxSidebarMenu[] = [
        {
          type: "main",
          label: "Documentation",
          items: [
            {
              title: "Introduction",
              url: "/docs/index",
            },
          ],
        },
      ]

      export default function RootLayout({ children }: { children: ReactNode }) {
        return (
          <html
            lang="en"
            suppressHydrationWarning
            className={`${geistSans.variable} ${geistMono.variable} h-full antialiased`}
          >
            <body>
              <NoxLayout
                defaultTheme="system"
                targetDir={["/docs"]}
                menu={sidebarMenu}
              >
                {children}
              </NoxLayout>
            </body>
          </html>
        )
      }

      ```
    </CodeBlock>

  </TabsContent>

### Buat route tangkap-semua

- Buat `app/[...docs]/page.tsx` yang merender `NoxRender` dengan `dir` dan `slug` dari URL:

<PackageManagerTabs bash>{`
mkdir "app/[...docs]"
touch "app/[...docs]/page.tsx"
`}</PackageManagerTabs>

- Isi `app/[...docs]/page.tsx` dengan kode berikut:

<CodeBlock filename="app/[...docs]/page.tsx">
```tsx
import { NoxRender } from "noxkit"

export default async function DocsPage({
  params,
}: {
  params: Promise<{ docs?: string[] }>
}) {
  const { docs = [] } = await params
  const segments = docs[0] === "docs" ? docs.slice(1) : docs

return <NoxRender dir="/docs" slug={segments.join("/")} />
}

````

</CodeBlock>

### Buat folder konten MDX

- Buat folder `content` dan `content/docs`, lengkap dengan `meta.ts` untuk label dan urutan navigasi:

<PackageManagerTabs bash>{`
mkdir -p "content/docs"
touch "content/docs/index.mdx"
`}</PackageManagerTabs>

- Isi `content/docs/index.mdx` dengan kode berikut:

<CodeBlock filename="content/docs/index.mdx">
```mdx
---
title: "Introduction"
description: "Pengenalan framework"
---

# Introduction

Selamat datang di dokumentasi noxkit.

````

</CodeBlock>

> **Jalankan**: `npm run dev` dan buka `http://localhost:3000` dan `http://localhost:3000/docs/` untuk melihat halaman dokumentasi.
