# Installation

**Nox** adalah starter untuk situs dokumentasi berbasis MDX. Ada dua cara memasangnya: **menggunakan template** (disarankan) atau **secara manual**. Halaman ini memandu Anda melewati kedua cara tersebut langkah demi langkah.

## Use Template

1. Jalankan perintah berikut di terminal:

   <CodeBlock filename="terminal">
     ```bash
     npx nox@latest template
     ```
   </CodeBlock>

2. Pilih template yang diinginkan — **nextjs**, atau **vite**:

   <TerminalView title="npx nox@latest template">
     <Command status="info">npx nox@latest template</Command>
     <ResultsProcess>
       <Question>Pilih template yang diinginkan:</Question>
       <Option selected description="Next.js dengan app router">nextjs</Option>
       <Option>vite</Option>
     </ResultsProcess>
   </TerminalView>

3. Proyek yang diinginkan akan dihasilkan secara otomatis.

### NextJS Template Structure

Template NextJS sudah disiapkan sehingga Anda tidak perlu mengonfigurasi apa pun:

1. **`layout.tsx` sudah terupdate** — root layout sudah memuat `NoxLayout`, `ThemeProvider`, dan font, lengkap dengan `sidebarMenu`.

2. **Otomatis dibuatkan `[...docs]/page.tsx`** — route tangkap-semua yang merender file MDX dari folder `content/docs`.

3. **Otomatis dibuatkan folder penyimpanan file MDX** — `content` dan `content/docs`:

   <ProjectTree name="project">
     <Folder name="content" open>
       <Folder name="docs" open>
         <File name="index.mdx" />
         <File name="setup.mdx" />
       </Folder>
     </Folder>
   </ProjectTree>

### Saat Deploy

Sebelum deploy, dua hal perlu diperhatikan:

1. **Update `eslint.config.ts`** — pastikan isinya sebagai berikut:

   <CodeBlock filename="eslint.config.ts">
     ```ts
     import { nextJsConfig } from "@workspace/eslint-config/next-js"

     /** @type {import("eslint").Linter.Config} */
     export default nextJsConfig
     ```
   </CodeBlock>

2. **Hapus `type module` di `package.json`** — hapus baris berikut agar aplikasi tidak di-deploy sebagai ES module:

   ```json
   {
     "type": "module"
   }
   ```

## Use Manual

1. Masuk ke folder project:

   <CodeBlock filename="terminal">
     ```bash
     cd nama-project
     ```
   </CodeBlock>

2. Jalankan perintah init:

   <CodeBlock filename="terminal">
     ```bash
     npx nox@latest init
     ```
   </CodeBlock>

3. **Update `layout.tsx`** — ganti isi root layout dengan kode berikut:

   <CodeBlock filename="app/layout.tsx">
     ```tsx
     import { Geist_Mono, Oxanium } from "next/font/google"
     import "@workspace/ui/globals.css"
     const oxanium = Oxanium({ subsets: ["latin"], variable: "--font-sans" })

     import { ThemeProvider } from "@/components/theme-provider"
     import { cn } from "@workspace/ui/lib/utils"

     import { NoxLayout } from "@nox/layouts/"
     import type { SidebarMenu } from "@nox/layouts/"

     export const sidebarMenu: SidebarMenu[] = [
       {
         type: "main",
         label: "Menus",
         items: [
           {
             title: "Home",
             url: "/",
           },
           {
             title: "Documentation",
             url: "/docs",
           },
           {
             title: "Blogs",
             url: "/blogs",
           },
         ],
       },
     ]

     const fontMono = Geist_Mono({
       subsets: ["latin"],
       variable: "--font-mono",
     })

     export default function RootLayout({
       children,
     }: Readonly<{
       children: React.ReactNode
     }>) {
       return (
         <html
           lang="en"
           suppressHydrationWarning
           className={cn(
             "antialiased",
             fontMono.variable,
             "font-sans",
             oxanium.variable
           )}
         >
           <body>
             <ThemeProvider>
               <NoxLayout targetDir={["/"]} menu={sidebarMenu}>
                 {children}
               </NoxLayout>
             </ThemeProvider>
           </body>
         </html>
       )
     }
     ```
   </CodeBlock>

4. **Buat `[...docs]/page.tsx` & `[...blogs]/page.tsx`** — route tangkap-semua untuk merender MDX:

   <CodeBlock filename="app/[...docs]/page.tsx">
     ```tsx
     import { MdxLayout } from "@nox/mdx-render/mdx-layout"

     export default async function DocsPage({
       params,
     }: {
       params: Promise<{ docs?: string[] }>
     }) {
       const { docs = [] } = await params
       const segments = docs[0] === "docs" ? docs.slice(1) : docs

       return <MdxLayout dir="/docs" slug={segments.join("/")} />
     }
     ```
   </CodeBlock>

   Jika ada folder `blogs`, perbaharui seperti berikut:

   <CodeBlock filename="app/[...blogs]/page.tsx">
     ```tsx
     import { MdxLayout } from "@nox/mdx-render/mdx-layout"

     export default async function DocsPage({
       params,
     }: {
       params: Promise<{ blogs?: string[] }>
     }) {
       const { blogs = [] } = await params
       const segments = blogs[0] === "blogs" ? blogs.slice(1) : blogs

       return <MdxLayout dir="/blogs" slug={segments.join("/")} />
     }
     ```
   </CodeBlock>

5. **Buat folder penyimpanan file MDX** — `content` dan `content/docs`; jika butuh, buat juga folder `content/blogs`:

   <ProjectTree name="project">
     <Folder name="content" open>
       <Folder name="docs" open>
         <File name="index.mdx" />
         <File name="setup.mdx" />
       </Folder>
       <Folder name="blogs" open>
         <File name="index.mdx" />
         <File name="setup.mdx" />
       </Folder>
     </Folder>
   </ProjectTree>
