# Installation

**Squadra** adalah CLI yang menyederhanakan workflow proyek monorepo (Turborepo) menjadi serangkaian perintah singkat. Halaman ini memandu Anda memasang CLI dan memahami setiap perintah yang tersedia: `squad list`, `squad create new`, dan `squad add`.

## Persyaratan

Pastikan Anda sudah menginstal:

- **Node.js** versi `20` atau lebih baru
- **pnpm** versi `10` atau lebih baru (untuk workspace & saat `squad` menjalankan install)
- Git

Periksa versi yang terpasang di mesin Anda:

<CodeBlock filename="terminal" inline>
  ```bash node -v && pnpm -v && git --version ```
</CodeBlock>

## 1. Instalasi CLI Secara Global

Pasang package `squadra` secara global — perintahnya tersedia sebagai `squad`:

<PackageManagerTabs>squadra -g</PackageManagerTabs>

Setelah terpasang, verifikasi versi CLI:

<CodeBlock filename="terminal" inline>
  ```bash squad --version ```
</CodeBlock>

<TerminalView title="squad --version">
  <Command>squad --version</Command>
  <ResultsProcess>
    <TerminalStep status="info">squadra/0.0.0 darwin-arm64 node-v24.19.0</TerminalStep>
  </ResultsProcess>
</TerminalView>

Jika `squad` belum dikenali, pastikan direktori `bin` Node.js (tempat package global terpasang) sudah ada di `PATH` — bisa dijalankan dengan `corepack enable` jika menggunakan pnpm yang terpasang via Corepack.

## 3. Membuat Proyek Baru — `squad create new`

`squad create new` membuat proyek Turborepo baru dari template, lengkap dengan app pilihan Anda di dalam folder `apps/`. Perintah ini wajib dijalankan **sebelum** `squad add`.

### Penggunaan

<CodeBlock filename="terminal" inline>
  ```bash squad create new [nama-proyek] ```
</CodeBlock>

| Flag             | Alias | Deskripsi                                                                                |
| ---------------- | ----- | ---------------------------------------------------------------------------------------- |
| `[nama-proyek]`  | —     | Nama proyek; bila diisi, prompt nama proyek dilewati                                     |
| `--apps`         | —     | App yang dibuat di `apps/` (pisahkan dengan koma, opsional `:nama`): `nextjs`, `vite-react`, `nestjs`, `blank` |
| `--skipInstall`  | `-i`  | Lewati `pnpm install` setelah proyek dibuat                                               |

### Contoh interaktif

Tanpa argumen, CLI bertanya nama proyek, tipe app, dan nama tiap app satu per satu:

    </TerminalStep>
    <Question>Pilih tipe proyek yang dibuat di dalam folder apps:</Question>
    <Option selected description="React framework dengan app router">
      Next.js
    </Option>
    <Option>Vite React</Option>
    <Option>NestJS</Option>
    <Option>Blank</Option>

  </ResultsProcess>
</TerminalView>

### Contoh non-interaktif

Semua pilihan bisa diberikan lewat flag agar tidak ada prompt:

<CodeBlock filename="terminal">
  ```bash

  ```
</CodeBlock>

Proyek yang dihasilkan kurang lebih seperti ini:

## 4. Menambahkan App ke Proyek — `squad add`

`squad add` menambahkan app baru (Next.js, Vite React, atau NestJS) ke folder `apps/` pada proyek Turborepo yang sudah ada. Jalankan dari **dalam** proyek hasil `squad create new`.

### Penggunaan

<CodeBlock filename="terminal" inline>
  ```bash squad add [--apps <tipe:nama>] [-i] ```
</CodeBlock>

| Flag            | Alias | Deskripsi                                                                      |
| --------------- | ----- | ------------------------------------------------------------------------------ |
| `--apps`        | —     | App yang ditambahkan (pisahkan dengan koma, opsional `:nama`): `nextjs`, `vite-react`, `nestjs` |
| `--skipInstall` | `-i`  | Lewati `pnpm install` setelah app ditambahkan                                  |

### Contoh interaktif

Tanpa `--apps`, CLI menampilkan pilihan tipe proyek dan meminta nama:

  <ResultsProcess>

    <Option>NestJS</Option>

### Contoh non-interaktif

<CodeBlock filename="terminal">
  ```bash

  ```
</CodeBlock>

## 5. Membatalkan Proses Interaktif

Semua prompt di `squad add` dan `squad create new` bisa dibatalkan kapan saja dengan `Ctrl+C` — CLI menampilkan pesan batal dan menghentikan proses:

## 6. Menjalankan Proyek yang Sudah Dibuat

Setelah proyek dibuat (dengan `squad create new`) dan app ditambahkan (dengan `squad add`), jalankan seluruh app sekaligus dari root proyek:

<CodeBlock filename="terminal">
  ```bash
  cd my-repo
  pnpm dev
  ```
</CodeBlock>

## Penyelesaian Masalah

| Masalah                                  | Solusi                                                              |
| ---------------------------------------- | ------------------------------------------------------------------- |
| `squad` tidak dikenali                   | Instal ulang global: `pnpm add -g squadra` atau `npm install -g squadra` |
| `squad add` tidak berjalan               | Jalankan di dalam proyek hasil `squad create new` (bukan di folder lain) |
| Nama app tidak valid                     | Gunakan huruf, angka, titik, strip (`-`), dan underscore (`_`)      |
| Folder proyek sudah ada & tidak kosong   | Gunakan nama proyek lain atau bersihkan folder tersebut             |
| Dependency tidak sinkron                 | Hapus cache lalu pasang ulang: `rm -rf node_modules && pnpm install` |
