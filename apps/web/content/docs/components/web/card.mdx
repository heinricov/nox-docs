# Card

Komponen `Card` adalah wadah fleksibel untuk mengelompokkan konten, seperti statistik, produk, atau artikel.

## Import

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from "mdxui/ui/card"
```

## Contoh Penggunaan

```tsx
<Card>
  <CardHeader>
    <CardTitle>Total Pengguna</CardTitle>
    <CardDescription>Statistik bulan ini</CardDescription>
  </CardHeader>
  <CardContent>
    <p className="text-3xl font-bold">12.480</p>
  </CardContent>
  <CardFooter>
    <p className="text-sm text-muted-foreground">Naik 8% dari bulan lalu</p>
  </CardFooter>
</Card>
```

## Struktur Bagian

- `CardHeader` — bagian atas berisi judul dan deskripsi
- `CardContent` — konten utama
- `CardFooter` — bagian bawah untuk aksi atau catatan

## Prop

| Prop      | Tipe     | Default | Deskripsi            |
| --------- | -------- | ------- | -------------------- |
| `className` | `string` | —     | Kelas tambahan        |
| `asChild` | `boolean` | `false` | Render sebagai elemen lain |

> **Catatan:** `Card` bersifat presentasional — kelola data dan state di komponen induk.
