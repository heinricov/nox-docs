# Introduction

Selamat datang di dokumentasi **Squadra**. Halaman ini adalah contoh konten yang ditulis dengan Markdown/MDX untuk menunjukkan berbagai elemen yang didukung.

## Apa itu Squadra?

Squadra adalah sekumpulan _komponen UI_ yang dirancang dengan baik untuk membangun aplikasi Anda. Konsep intinya sederhana: **tulis konten Anda sebagai `.mdx`**, dan framework akan merender sisanya.

## Fitur Utama

- Server Component secara default
- Sidebar otomatis dari struktur folder
- Dark mode dan theming
- Dukungan MDX penuh

## Contoh Inline Code

Untuk memulai, gunakan perintah:

```bash
pnpm dev
```

Atau buka halaman dokumentasi di `localhost:3000/docs`.

## Kutipan

> Dokumentasi yang baik adalah fondasi dari produk yang baik.

## Tabel Perbandingan

| Fitur        | Status | Catatan                  |
| ------------ | :----: | ------------------------ |
| Server First |   ✅   | Default di App Router    |
| MDX          |   ✅   | Pakai `next-mdx-remote`  |
| Sidebar      |   ✅   | Otomatis dari `content/` |

## Daftar Berurutan

1. Buat folder di dalam `apps/docs/content/`
2. Tambahkan file `meta.ts` untuk mengatur label dan urutan
3. Tulis file `.mdx` untuk setiap halaman
