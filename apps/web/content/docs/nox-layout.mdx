# NoxLayout

NoxLayout adalah layout utama noxkit: header, sidebar, konten, dan footer dalam satu komponen, dan dapat digunakan untuk membuat layout halaman dokumentasi MDX.
NoxLayout dapat diatur melalui props yang dimiliki oleh komponen ini. Seperti :

## children

Prop children adalah konten halaman (wajib), dan akan ditampilkan di dalam layout yang membungkus konten.

<CodeBlock filename="app/layout.tsx" highlightText={[[12, "children"]]}>
  ```tsx
      import "./globals.css"
      import { NoxLayout } from "noxkit"

      export default function RootLayout({
        children,
      }: Readonly<{
        children: React.ReactNode
        }>) {
        return (
          <html
            lang="en"
            suppressHydrationWarning
          >
            <body>
              <NoxLayout>
                {children}
              </NoxLayout>
            </body>
          </html>
        )
      }

```
</CodeBlock>

> Hal yang perlu di pastikan adalah :
>
> - Prop `children` (wajib) adalah konten halaman yang akan ditampilkan di dalam layout.
> - `suppressHydrationWarning` adalah prop yang digunakan untuk menghilangkan warning hydration.

## Props

| Prop           | Tipe                            | Default            | Deskripsi                                                    |
| -------------- | ------------------------------- | ------------------ | ------------------------------------------------------------ |
| `menu`         | `NoxSidebarMenu[]`              | —                  | Menu sidebar (wajib). Definisikan struktur navigasi sidebar. |
| `children`     | `ReactNode`                     | —                  | Konten halaman (wajib).                                      |
| `targetDir`    | `string \| string[]`            | —                  | Direktori target yang menentukan kapan sidebar ditampilkan.  |
| `defaultTheme` | `"light" \| "dark" \| "system"` | `"system"`         | Tema default untuk situs.                                    |
| `groupmenu`    | `GroupMenuItem[]`               | —                  | Menu grup tambahan untuk sidebar.                            |
| `navheader`    | `ReactNode`                     | `<DefaultHeader>`  | Komponen header kustom.                                      |
| `navside`      | `ReactNode`                     | `<DefaultSidebar>` | Komponen sidebar kustom.                                     |
| `navfooter`    | `ReactNode`                     | `<DefaultFooter>`  | Komponen footer kustom.                                      |
| `githubUrl`    | `string`                        | —                  | URL GitHub untuk link di header dan footer.                  |
| `twitterUrl`   | `string`                        | —                  | URL Twitter untuk link di header dan footer.                 |
| `copyRight`    | `string`                        | —                  | Teks copyright di footer.                                    |
| `logo`         | `ReactNode`                     | —                  | Komponen logo kustom untuk header dan footer.                |
```
