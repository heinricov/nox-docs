title: "NoxLayout"
description: "Layout utama noxkit: header, sidebar, konten, dan footer dalam satu komponen"
---

`NoxLayout` adalah komponen layout utama noxkit yang menyusun **header**, **sidebar**, **area konten**, dan **footer** dalam satu kerangka responsif. Cukup bungkus halaman aplikasi Anda dengannya, dan struktur dokumentasi siap dipakai.

## Fitur Utama

- **`navheader`** — header sticky dengan logo, navigasi, tombol toggle sidebar (mobile), pencarian, dan tombol tema; default dari `default-header.tsx`
- **`navside`** — sidebar navigasi yang menerima menu dari props `menu`, default `DefaultSidebar` dari `default-sidebar.tsx`; tersembunyi otomatis di layar kecil
- **`SidebarInset`** — area konten utama yang menyesuaikan posisi sidebar
- **`navfooter`** — footer dengan link, sosial, dan copyright; default dari `default-footer.tsx`
- **Responsif** — sidebar selalu tampil di desktop; di bawah `1024px` hanya tampil pada path yang ditentukan `targetDir`
- **TooltipProvider** — provider tooltip global, jadi tooltip langsung berfungsi di seluruh halaman

## Props

| Prop         | Tipe                 | Deskripsi                                                        |
| ------------ | -------------------- | ---------------------------------------------------------------- |
| `menu`       | `NoxSidebarMenu[]`   | Daftar menu yang dirender di sidebar (wajib)                     |
| `children`   | `ReactNode`          | Konten halaman yang dibungkus di dalam area konten (wajib)       |
| `targetDir`  | `string \| string[]` | Prefix path dokumentasi; sidebar ikut tampil di path tersebut    |
| `navheader`  | `ReactNode`          | Konten header; default `DefaultHeader` dari `default-header.tsx` |
| `navside`    | `ReactNode`          | Konten sidebar; default `DefaultSidebar` dari `default-sidebar.tsx` |
| `navfooter`  | `ReactNode`          | Konten footer; default `DefaultFooter` dari `default-footer.tsx` |
| `githubUrl`  | `string`             | URL akun GitHub user; menampilkan ikon GitHub di header & footer (opsional) |
| `twitterUrl` | `string`             | URL akun Twitter/X user; menampilkan ikon Twitter/X di header & footer (opsional) |
| `copyRight`  | `string`             | Teks copyright di footer; default `Copyright © {tahun} Bloxxee. All rights reserved.` |
| `logo`       | `ReactNode`          | Logo kustom di header & footer; default `NavLogo` dari `nav-logo.tsx` |

## Struktur Menu

Tipe `NoxSidebarMenu` terdiri dari dua varian:

- **`main`** — menu datar dengan item `title`, `url`, dan `icon` opsional
- **`collaps`** — menu berisi item yang bisa di-expand, tiap item boleh punya sub-item `items`

<CodeBlock filename="sidebar-menu.ts">
```ts
import type { NoxSidebarMenu } from "noxkit"

const menu: NoxSidebarMenu[] = [
{
type: "main",
label: "Menus",
items: [
{ title: "Home", url: "/" },
{ title: "Documentation", url: "/docs" },
],
},
{
type: "collaps",
label: "Components",
items: [
{
title: "Tools",
url: "#",
items: [
{ title: "Code Block", url: "/components/code-block" },
{ title: "Inline", url: "/components/inline" },
],
},
],
},
]

````
</CodeBlock>

## Penggunaan

### 1. Definisikan menu

Buat file `sidebar-menu.ts` di proyek Anda, lalu ekspor array `NoxSidebarMenu` seperti contoh di atas.

### 2. Gunakan di Root Layout

Bungkus seluruh aplikasi di `app/layout.tsx`. Contoh:

<CodeBlock filename="app/layout.tsx">
```tsx
import type { NoxSidebarMenu } from "noxkit"
import { NoxLayout } from "noxkit"
import { sidebarMenu } from "@/lib/sidebar-menu"

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en">
      <body>
        <NoxLayout targetDir={["/docs"]} menu={sidebarMenu}>
          {children}
        </NoxLayout>
      </body>
    </html>
  )
}
````

</CodeBlock>

### 3. Bungkus provider lain di luar NoxLayout

Komponen seperti `ThemeProvider` (dark mode) dipasang di luar `NoxLayout`:

<CodeBlock filename="app/layout.tsx">
  ```tsx
  <body>
    <ThemeProvider>
      <NoxLayout targetDir={["/docs"]} menu={sidebarMenu}>
        {children}
      </NoxLayout>
    </ThemeProvider>
  </body>
  ```
</CodeBlock>

## Perilaku Responsif

`NoxLayout` menentukan tampilan sidebar dengan `useMediaQuery("(min-width: 1024px)")` dan `usePathname`:

- **Desktop (`≥1024px`)** — sidebar selalu tampil di semua halaman
- **Mobile (`<1024px`)** — sidebar disembunyikan, kecuali pathname cocok dengan `targetDir`; di bawah `640px` sidebar menjadi sheet yang dibuka lewat tombol hamburger di header

`targetDir` bisa berisi satu path (`"/docs"`) atau beberapa path (`["/docs", "/api"]`). Path cocok jika sama persis atau diawali `dir/`, jadi `/docs/introduction` tetap menampilkan sidebar.

## Penjelasan Alur

1. `NoxLayout` menerima `menu`, `children`, `targetDir`, `navheader`, `navside`, `navfooter`, `githubUrl`, `twitterUrl`, `copyRight`, dan `logo`
2. `usePathname` membaca path aktif, `useMediaQuery` mendeteksi ukuran layar
3. `showSidebar` dihitung: `!isDesktop || isTargetPath`
4. `SidebarProvider` membungkus `navheader`, baris `navside + SidebarInset`, dan `navfooter`
5. `children` dirender di dalam `SidebarInset` dengan padding dan jarak antar konten

## Kustomisasi Header, Sidebar & Footer

`NoxLayout` menyediakan tiga props untuk menyesuaikan header, sidebar, dan footer tanpa mengubah struktur kerangka:

- **`navheader`** — menerima `ReactNode`; default-nya komponen `DefaultHeader` dari `default-header.tsx`
- **`navside`** — menerima `ReactNode`; default-nya komponen `DefaultSidebar` dari `default-sidebar.tsx`
- **`navfooter`** — menerima `ReactNode`; default-nya komponen `DefaultFooter` dari `default-footer.tsx`

Selama props tidak diberikan, `NoxLayout` otomatis memakai komponen default-nya masing-masing.

### Custom Header

Buat komponen header Anda sendiri, lalu kirim lewat prop `navheader`. Header default menggunakan `useSidebar` dari `noxkit/components/sidebar`, jadi Anda bisa memakainya juga untuk tombol toggle sidebar:

<CodeBlock filename="components/site-header.tsx">
```tsx
"use client"

import Link from "next/link"
import { usePathname } from "next/navigation"
import { PanelLeftIcon } from "lucide-react"

import { Button } from "noxkit/components/button"
import { useSidebar } from "noxkit/components/sidebar"

export function SiteHeader() {
  const { toggleSidebar } = useSidebar()
  const pathname = usePathname()

  return (
    <header className="sticky top-0 z-50 flex h-16 w-full items-center border-b bg-background px-4">
      <Button
        className="shrink-0 lg:hidden"
        variant="ghost"
        size="icon"
        aria-label="Toggle sidebar"
        onClick={toggleSidebar}
      >
        <PanelLeftIcon />
      </Button>
      <span className="ml-4 text-sm font-semibold">
        {pathname === "/" ? "Home" : "Docs"}
      </span>
    </header>
  )
}
````
</CodeBlock>

### Custom Footer

Buat komponen footer sendiri, lalu kirim lewat prop `navfooter`:

<CodeBlock filename="components/site-footer.tsx">
```tsx
export function SiteFooter() {
  return (
    <footer className="border-t bg-background px-4 py-6">
      <p className="text-center text-sm text-muted-foreground">
        &copy; {new Date().getFullYear()} My Company
      </p>
    </footer>
  )
}
````
</CodeBlock>

### Custom Sidebar

Buat komponen sidebar sendiri, lalu kirim lewat prop `navside`. Sidebar default memakai `Sidebar`, `SidebarContent`, dan `NavMain`/`NavCollaps` dari `noxkit`, jadi Anda bisa menyusunnya ulang sesuka hati:

<CodeBlock filename="components/site-sidebar.tsx">
```tsx
import { NavCollaps } from "noxkit/layouts/nav-collaps"
import { NavMain } from "noxkit/layouts/nav-main"
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarHeader,
} from "noxkit/components/sidebar"
import type { NoxSidebarMenu } from "noxkit"

export function SiteSidebar({ menu }: { menu: NoxSidebarMenu[] }) {
  return (
    <Sidebar>
      <SidebarHeader />
      <SidebarContent>
        {menu.map((item, index) => (
          <div key={`${item.type}-${item.label}-${index}`}>
            {item.type === "main" ? (
              <NavMain label={item.label} items={item.items} />
            ) : (
              <NavCollaps label={item.label} items={item.items} />
            )}
          </div>
        ))}
      </SidebarContent>
      <SidebarFooter />
    </Sidebar>
  )
}
````
</CodeBlock>

### Pakai di NoxLayout

`navheader`, `navside`, dan `navfooter` diganti di tempat pemasangan `NoxLayout`:

<CodeBlock filename="app/layout.tsx">
```tsx
import { NoxLayout } from "noxkit"
import { sidebarMenu } from "@/lib/sidebar-menu"
import { SiteHeader } from "@/components/site-header"
import { SiteSidebar } from "@/components/site-sidebar"
import { SiteFooter } from "@/components/site-footer"

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en">
      <body>
        <NoxLayout
          targetDir={["/docs"]}
          menu={sidebarMenu}
          navheader={<SiteHeader />}
          navside={<SiteSidebar menu={sidebarMenu} />}
          navfooter={<SiteFooter />}
        >
          {children}
        </NoxLayout>
      </body>
    </html>
  )
}
````
</CodeBlock>

### Menyembunyikan Header, Sidebar, atau Footer

Berikan `navheader={null}`, `navside={null}`, atau `navfooter={null}` bila ingin menghapus bagian tersebut sepenuhnya:

<CodeBlock filename="app/layout.tsx">
```tsx
<NoxLayout
  targetDir={["/docs"]}
  menu={sidebarMenu}
  navheader={null}
  navside={null}
>
  {children}
</NoxLayout>
````
</CodeBlock>
