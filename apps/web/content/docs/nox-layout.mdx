title: "NoxLayout"
description: "Layout utama noxkit: header, sidebar, konten, dan footer dalam satu komponen"
---

`NoxLayout` adalah komponen layout utama yang menyatukan **header**, **sidebar**, **konten**, dan **footer** dalam satu bungkusan. Cukup bungkus `<NoxLayout>` di sekitar `{children}` pada file `layout.tsx` kamu, dan seluruh struktur halaman dokumentasi sudah siap.

## Instalasi

Pasang noxkit di proyek kamu, lalu gunakan `NoxLayout` di file layout root.

      ```tsx
            {

        )
      }
      ```

## Props

| Prop           | Tipe                            | Default                                                  | Wajib  | Deskripsi                                                           |
| -------------- | ------------------------------- | -------------------------------------------------------- | ------ | ------------------------------------------------------------------- |
| `menu`         | `NoxSidebarMenu[]`              | —                                                        | **Ya** | Struktur navigasi sidebar.                                          |
| `children`     | `ReactNode`                     | —                                                        | **Ya** | Konten halaman yang ditampilkan di dalam layout.                    |
| `targetDir`    | `string \| string[]`            | —                                                        | Tidak  | Direktori URL yang menentukan kapan sidebar tampil di desktop.      |
| `defaultTheme` | `"light" \| "dark" \| "system"` | `"system"`                                               | Tidak  | Tema warna default.                                                 |
| `groupmenu`    | `GroupMenuItem[]`               | —                                                        | Tidak  | Menu grup / version switcher di sidebar.                            |
| `githubUrl`    | `string`                        | —                                                        | Tidak  | URL profil GitHub — menampilkan ikon GitHub di header & footer.     |
| `twitterUrl`   | `string`                        | —                                                        | Tidak  | URL profil Twitter/X — menampilkan ikon Twitter di header & footer. |
| `copyRight`    | `string`                        | `"Copyright (c) {tahun} Nox Docs. All rights reserved."` | Tidak  | Teks copyright di footer.                                           |
| `logo`         | `ReactNode`                     | `<NavLogo />`                                            | Tidak  | Logo kustom untuk header dan footer.                                |
| `navheader`    | `ReactNode`                     | `<DefaultHeader />`                                      | Tidak  | Ganti seluruh komponen header.                                      |
| `navside`      | `ReactNode`                     | `<DefaultSidebar />`                                     | Tidak  | Ganti seluruh komponen sidebar.                                     |
| `navfooter`    | `ReactNode`                     | `<DefaultFooter />`                                      | Tidak  | Ganti seluruh komponen footer.                                      |

## Props Penting

### `children`

Konten halaman yang akan ditampilkan di dalam layout. Ini adalah satu-satunya prop yang **wajib** selain `menu`.

<CodeBlock filename="app/layout.tsx" highlightText={[[12, "children"]]}>
```tsx
import { NoxLayout } from "noxkit"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <NoxLayout menu={sidebarMenu}>
          {children}
        </NoxLayout>
      </body>
    </html>
  )
}
```
</CodeBlock>

> **Catatan:** Pastikan `<html>` memiliki prop `suppressHydrationWarning` untuk mencegah warning hydration dari sistem tema.

---

### `menu`

Definisikan seluruh struktur navigasi sidebar. Setiap item dalam array memiliki `type` yang menentukan cara render-nya.

| Tipe            | Deskripsi                                                                        |
| --------------- | -------------------------------------------------------------------------------- |
| `"main"`        | Daftar link datar — cocok untuk navigasi biasa.                                  |
| `"main-mobile"` | Sama seperti `"main"`, tapi hanya tampil di mobile.                              |
| `"collaps"`     | Bagian yang bisa di-collapse (buka/tutup) — cocok untuk dokumentasi ber nesting. |

<CodeBlock filename="app/layout.tsx" highlightLine={[5, 17, 29]}>
```tsx
import type { NoxSidebarMenu } from "noxkit"

export const sidebarMenu: NoxSidebarMenu[] = [
  // Link datar
  {
    type: "main",
    label: "Getting Started",
    items: [
      { title: "Introduction", url: "/docs/index" },
      { title: "Installation", url: "/docs/installation" },
    ],
  },
  // Link yang bisa di-collapse
  {
    type: "collaps",
    label: "Components",
    items: [
      {
        title: "Button",
        url: "/docs/components/button",
        items: [
          { title: "Variants", url: "/docs/components/button#variants" },
          { title: "Sizes", url: "/docs/components/button#sizes" },
        ],
      },
    ],
  },
]
```
</CodeBlock>

**Opsi item:**

| Prop       | Tipe               | Deskripsi                                                          |
| ---------- | ------------------ | ------------------------------------------------------------------ |
| `title`    | `string`           | Teks link.                                                         |
| `url`      | `string`           | Path tujuan link.                                                  |
| `icon`     | `ReactNode`        | _(opsional)_ Ikon di sebelah kiri teks.                            |
| `group`    | `string`           | _(opsional)_ Grup — digunakan bersama `groupmenu` untuk filtering. |
| `isActive` | `boolean`          | _(opsional, type `collaps`)_ Mulai dalam keadaan terbuka.          |
| `items`    | `{ title, url }[]` | _(opsional, type `collaps`)_ Sub-item di bawah item ini.           |

### `targetDir`

Mengontrol **kapan sidebar tampil di desktop**. Terima satu string atau array string berisi path prefix URL.

- **Desktop (>= 1024px):** Sidebar hanya tampil jika pathname saat ini cocok dengan salah satu `targetDir`.
- **Mobile (< 1024px):** Sidebar selalu tersedia melalui tombol hamburger di header.

<CodeBlock
  filename="app/layout.tsx"
  highlightText={[[21, 'targetDir={["/docs", "/components"]}']]}
>
  ```tsx
  <NoxLayout menu={sidebarMenu} targetDir={["/docs", "/components"]}>
    {children}
  </NoxLayout>
  ```
</CodeBlock>

> Sidebar akan tampil di halaman `/docs/*` dan `/components/*`, tapi tersembunyi di halaman lain di desktop.

Jika `targetDir` tidak diisi, sidebar **tersembunyi di desktop** dan hanya bisa diakses lewat tombol toggle di mobile.

---

### `defaultTheme`

Tema warna awal yang diterapkan saat halaman pertama kali dimuat.

| Nilai      | Deskripsi                                     |
| ---------- | --------------------------------------------- |
| `"system"` | Mengikuti preferensi sistem operasi pengguna. |
| `"light"`  | Selalu gelap.                                 |
| `"dark"`   | Selalu terang.                                |

Pilihan pengguna otomatis disimpan ke `localStorage` dan disinkronkan antar tab. Toggle tema tersedia di header, atau tekan tombol **D** di keyboard.

---

### `groupmenu`

Menambahkan dropdown **version / grup switcher** di bagian atas sidebar. Berguna jika dokumentasi kamu punya beberapa versi (misal v1, v2, v3).

<CodeBlock filename="app/layout.tsx" highlightText={[[21, "groupmenu={versionMenu}"]]}>
```tsx
import type { GroupMenuItem } from "noxkit"

const versionMenu: GroupMenuItem[] = [
{
title: "v2.0",
icon: <span>v2</span>,
description: "Versi terbaru dengan fitur baru",
},
{
title: "v1.0",
icon: <span>v1</span>,
description: "Versi lama (legacy)",
},
]

<NoxLayout
  menu={sidebarMenu}
  groupmenu={versionMenu}
>
  {children}
</NoxLayout>
```
</CodeBlock>

Setelah dipilih, sidebar akan **otomatis memfilter** item `menu` berdasarkan field `group` yang cocok dengan judul grup yang aktif.

### Komponen Kustom: `navheader`, `navside`, `navfooter`

Untuk kontrol penuh atas tampilan header, sidebar, atau footer, ganti seluruh komponennya melalui props berikut:

| Prop        | Komponen Default     | Deskripsi                                                                                     |
| ----------- | -------------------- | --------------------------------------------------------------------------------------------- |
| `navheader` | `<DefaultHeader />`  | Header — berisi tombol toggle sidebar, logo, navigasi, search form, tombol tema, ikon sosial. |
| `navside`   | `<DefaultSidebar />` | Sidebar — berisi dropdown grup, menu items, dan logo footer (mobile).                         |
| `navfooter` | `<DefaultFooter />`  | Footer — berisi logo, ikon sosial, link, dan copyright.                                       |

<CodeBlock filename="app/layout.tsx">
```tsx
function CustomHeader() {
  return (
    <header className="border-b p-4">
      <h1>My Custom Header</h1>
    </header>
  )
}

<NoxLayout
  menu={sidebarMenu}
  navheader={<CustomHeader />}
>
  {children}
</NoxLayout>
```
</CodeBlock>

## Fitur Tambahan

### Tema dengan Hotkey

Sistem tema terintegrasi dengan dukungan hotkey — tekan **D** di keyboard untuk toggle antara light dan dark (dikecualikan saat sedang mengetik di input/textarea).

### Anti-Flicker pada Load

Script inline disuntikkan sebelum halaman dirender untuk menerapkan tema dari `localStorage` segera — mencegahkedip (flash) saat halaman pertama kali dimuat.

### Sinkronisasi Antar Tab

Perubahan tema di satu tab otomatis disinkronkan ke tab lain melalui event `localStorage`.

## Tipe Data

### `NoxSidebarMenu`

<CodeBlock filename="NoxSidebarMenu.ts">
```ts
type NoxSidebarMenu = NavMainMenu | NavMainMobileMenu | NavCollapsMenu

type NavMainMenu = {
type: "main"
label?: string | null
group?: string
items: NavMainItem[]
}

type NavMainMobileMenu = {
type: "main-mobile"
label?: string | null
group?: string
items: NavMainItem[]
}

type NavCollapsMenu = {
type: "collaps"
label?: string | null
group?: string
items: NavCollapsItem[]
}

type NavMainItem = {
title: string
url: string
icon?: ReactNode
group?: string
}

type NavCollapsItem = {
title: string
url: string
icon?: ReactNode
isActive?: boolean
group?: string
items?: { title: string; url: string }[]
}

````
</CodeBlock>
