`NoxLayout` adalah komponen layout utama nox yang menyusun **header**, **sidebar**, **area konten**, dan **footer** dalam satu kerangka responsif. Cukup bungkus halaman aplikasi Anda dengannya, dan struktur dokumentasi siap dipakai.

## Fitur Utama

- **SiteHeader** — header sticky dengan logo, navigasi, tombol toggle sidebar (mobile), pencarian, dan tombol tema
- **AppSidebar** — sidebar navigasi yang menerima menu dari props `menu`, tersembunyi otomatis di layar kecil
- **SidebarInset** — area konten utama yang menyesuaikan posisi sidebar
- **AppFooter** — footer dengan link, sosial, dan copyright
- **Responsif** — sidebar selalu tampil di desktop; di bawah `1024px` hanya tampil pada path yang ditentukan `targetDir`
- **TooltipProvider** — provider tooltip global, jadi tooltip langsung berfungsi di seluruh halaman

## Props

| Prop        | Tipe                 | Deskripsi                                                     |
| ----------- | -------------------- | ------------------------------------------------------------- |
| `menu`      | `SidebarMenu[]`      | Daftar menu yang dirender di sidebar (wajib)                  |
| `children`  | `ReactNode`          | Konten halaman yang dibungkus di dalam area konten (wajib)    |
| `targetDir` | `string \| string[]` | Prefix path dokumentasi; sidebar ikut tampil di path tersebut |

## Struktur Menu

Tipe `SidebarMenu` terdiri dari dua varian:

- **`main`** — menu datar dengan item `title`, `url`, dan `icon` opsional
- **`collaps`** — menu berisi item yang bisa di-expand, tiap item boleh punya sub-item `items`

<CodeBlock filename="sidebar-menu.ts">
```ts
import type { SidebarMenu } from "@nox/layouts/sidebar"

const menu: SidebarMenu[] = [
{
type: "main",
label: "Menus",
items: [
{ title: "Home", url: "/" },
{ title: "Documentation", url: "/docs" },
],
},
{
type: "collaps",
label: "Components",
items: [
{
title: "Tools",
url: "#",
items: [
{ title: "Code Block", url: "/components/code-block" },
{ title: "Inline", url: "/components/inline" },
],
},
],
},
]

````
</CodeBlock>

## Penggunaan

### 1. Definisikan menu

Buat file `sidebar-menu.ts` di proyek Anda, lalu ekspor array `SidebarMenu` seperti contoh di atas.

### 2. Gunakan di Root Layout

Bungkus seluruh aplikasi di `app/layout.tsx`. Contoh:

<CodeBlock filename="app/layout.tsx">
```tsx
import type { SidebarMenu } from "@nox/layouts/sidebar"
import { NoxLayout } from "@nox/layouts/nox-layout"
import { sidebarMenu } from "@/lib/sidebar-menu"

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en">
      <body>
        <NoxLayout targetDir={["/docs"]} menu={sidebarMenu}>
          {children}
        </NoxLayout>
      </body>
    </html>
  )
}
````

</CodeBlock>

### 3. Bungkus provider lain di luar NoxLayout

Komponen seperti `ThemeProvider` (dark mode) dipasang di luar `NoxLayout`:

<CodeBlock filename="app/layout.tsx">
  ```tsx
  <body>
    <ThemeProvider>
      <NoxLayout targetDir={["/docs"]} menu={sidebarMenu}>
        {children}
      </NoxLayout>
    </ThemeProvider>
  </body>
  ```
</CodeBlock>

## Perilaku Responsif

`NoxLayout` menentukan tampilan sidebar dengan `useMediaQuery("(min-width: 1024px)")` dan `usePathname`:

- **Desktop (`≥1024px`)** — sidebar selalu tampil di semua halaman
- **Mobile (`<1024px`)** — sidebar disembunyikan, kecuali pathname cocok dengan `targetDir`; di bawah `640px` sidebar menjadi sheet yang dibuka lewat tombol hamburger di header

`targetDir` bisa berisi satu path (`"/docs"`) atau beberapa path (`["/docs", "/api"]`). Path cocok jika sama persis atau diawali `dir/`, jadi `/docs/introduction` tetap menampilkan sidebar.

## Penjelasan Alur

1. `NoxLayout` menerima `menu`, `children`, dan `targetDir`
2. `usePathname` membaca path aktif, `useMediaQuery` mendeteksi ukuran layar
3. `showSidebar` dihitung: `!isDesktop || isTargetPath`
4. `SidebarProvider` membungkus `SiteHeader`, baris `AppSidebar + SidebarInset`, dan `AppFooter`
5. `children` dirender di dalam `SidebarInset` dengan padding dan jarak antar konten
