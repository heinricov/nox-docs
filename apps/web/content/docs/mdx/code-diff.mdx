---
title: "CodeDiff"
description: "Komponen untuk menampilkan perbandingan (diff) kode lama vs baru dalam satu kartu — mode berdampingan, inline, dan perubahan nama file, dengan tombol salin"
---

`CodeDiff` menampilkan **perbandingan kode** (diff) antara versi lama dan baru dalam satu kartu. Baris yang berubah ditandai otomatis: **merah** untuk kode lama (dihapus) dan **hijau** untuk kode baru (ditambahkan).

Ada tiga varian:

- **Berdampingan (default)** — panel **Old** dan **New** sejajar, baris yang berubah di-highlight.
- **Inline** — perubahan ditampilkan berurutan dalam satu kolom dengan penanda `-` / `+`.
- **Ganti nama file** — lewat `<OldFile>` / `<NewFile>`, nama file tampil di header tiap panel.

## Import

Di file MDX, `CodeDiff`, `OldCode`, `NewCode`, `OldFile`, dan `NewFile` sudah terdaftar otomatis di `MdxRenderer` — langsung bisa dipakai tanpa import.

Di file React/TSX, import terlebih dahulu:

<CodeBlock inline>
  ```tsx import {CodeDiff, OldCode, NewCode} from "mdxui" ```
</CodeBlock>

## Props

| Prop       | Tipe        | Deskripsi                                                                             |
| ---------- | ----------- | ------------------------------------------------------------------------------------- |
| `children` | `ReactNode` | `<OldCode>` / `<NewCode>` (atau `<OldFile>` / `<NewFile>`) berisi kode lama dan baru  |
| `filename` | `string`    | Nama file di judul kartu. Diabaikan bila `title` sudah diisi                          |
| `title`    | `string`    | Judul kartu, dipakai juga sebagai `aria-label`                                        |
| `inline`   | `boolean`   | Mode inline: perubahan tampil berurutan (`-` / `+`) dalam satu kolom, bukan dua panel |

### Sub-komponen

| Komponen  | Tipe        | Fungsi                                |
| --------- | ----------- | ------------------------------------- |
| `OldCode` | `ReactNode` | Menandai isi sebagai **kode lama**    |
| `NewCode` | `ReactNode` | Menandai isi sebagai **kode baru**    |
| `OldFile` | `ReactNode` | Kode lama + nama file di header panel |
| `NewFile` | `ReactNode` | Kode baru + nama file di header panel |

Semua sub-komponen menerima `children` (fenced code block di MDX, atau string di React) dan prop `filename`.

Berikan `children` berupa **fenced code block** di dalam `<OldCode>` dan `<NewCode>`. Bahasa mengikuti fence (misalnya `tsx`, `mdx`) dan ikut di-highlight.

## 3. Cara Kerja

1. Di MDX, fenced code block di dalam `<OldCode>` / `<NewCode>` diubah oleh `rehype-pretty-code` menjadi elemen `pre` / `figure` yang sudah di-highlight.
2. `CodeDiff` mengekstrak teks kode dari children — termasuk token highlight hasil de-duplikasi React Server Components — dengan menelusuri elemen secara rekursif.
3. Di React, children string yang dibungkus fence di-strip otomatis.
4. Baris lama vs baru dibandingkan satu-per-satu; baris yang berubah di-highlight **merah** (lama) dan **hijau** (baru).
5. Tombol salin menyalin **kode baru** (kode di panel `New`) ke clipboard.

---

## 4. Catatan

- `CodeDiff` adalah client component — gunakan langsung di file MDX tanpa memikirkan "use client".
- `filename` (dan `filename` pada sub-komponen) hanya **label semu** — tidak membaca file dari proyek.
- Mode `inline` otomatis dinonaktifkan saat memakai `<OldFile>` / `<NewFile>` — mode tersebut selalu menampilkan panel berdampingan agar nama file terlihat.
- Untuk konten yang berisi code block lagi (misalnya diff file `.mdx`), gunakan fence **lebih panjang** di bagian luar agar fence bagian dalam tidak menutupnya.
- `CodeDiff` dan sub-komponennya tersedia di dalam evaluasi `ComponentPreview` — `import { CodeDiff, OldCode, NewCode } from "mdxui"` bisa dipakai.
