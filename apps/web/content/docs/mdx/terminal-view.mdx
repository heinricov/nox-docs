title: "TerminalView"
description: "Menampilkan cuplikan interaksi CLI bergaya jendela terminal di dalam dokumentasi."
---

`TerminalView` membungkus **cuplikan interaksi CLI** dalam kartu bergaya jendela terminal — lengkap dengan titik lampu macOS, judul, latar gelap, dan font monospace. Cocok untuk mendokumentasikan alur perintah CLI seperti `npx create-next-app`, hasil eksekusi, hingga proses berjalan.

Komponen penyusunnya bersifat komposisional dan sejajar: `Command` untuk perintah, `QuestionStep` untuk pertanyaan interaktif, `Option` untuk pilihan menu, `SuccessProcess` untuk pesan sukses, serta `Process` untuk progres.

## Import

Di file MDX, `TerminalView` dan seluruh komponen penyusunnya sudah terdaftar otomatis di `MdxRenderer` — langsung bisa dipakai tanpa import.

Di file React/TSX, import terlebih dahulu:

<CodeBlock inline>
```tsx
import { TerminalView, Command, QuestionStep, Option, SuccessProcess, Result } from "noxkit/common/terminal-view"
```
</CodeBlock>

## Daftar komponen

| Komponen        | Fungsi                                                        |
| --------------- | ------------------------------------------------------------- |
| `TerminalView`  | Bungkus utama — jendela terminal dengan judul dan titik lampu |
| `Command`       | Baris perintah dengan glyph `❯`                               |
| `Result`        | Baris output perintah dengan warna abu-abu                    |
| `QuestionStep`  | Pertanyaan interaktif dengan glyph `?` atau ceklis `✔` jika `done` |
| `Option`        | Pilihan menu; `selected` memberi tanda `>` berwarna           |
| `SuccessProcess`| Pesan sukses dengan ceklis hijau `✔`                          |
| `Process`       | Progres berjalan dengan label dan persentase                  |

## Props

### TerminalView

| Prop       | Tipe        | Default      | Deskripsi                                  |
| ---------- | ----------- | ------------ | ------------------------------------------ |
| `title`    | `string`    | `"terminal"` | Teks judul di bar header jendela           |
| `className`| `string`    | —            | Kelas tambahan untuk menyesuaikan tampilan |
| `children` | `ReactNode` | —            | Konten di dalam jendela terminal (wajib)   |

### Command

| Prop       | Tipe        | Default | Deskripsi                    |
| ---------- | ----------- | ------- | ---------------------------- |
| `children` | `ReactNode` | —       | Teks perintah (wajib)        |
| `className`| `string`    | —       | Kelas tambahan               |

### QuestionStep

| Prop       | Tipe        | Default | Deskripsi                                        |
| ---------- | ----------- | ------- | ------------------------------------------------ |
| `question` | `string`    | —       | Teks pertanyaan (wajib)                          |
| `done`     | `boolean`   | `false` | Jika `true`, tampilkan ceklis `✔` kuning         |
| `children` | `ReactNode` | —       | `Option` children (opsional)                     |
| `className`| `string`    | —       | Kelas tambahan                                   |

### Option

| Prop         | Tipe        | Default | Deskripsi                            |
| ------------ | ----------- | ------- | ------------------------------------ |
| `children`   | `ReactNode` | —       | Nama pilihan (wajib)                 |
| `selected`   | `boolean`   | `false` | Tandai pilihan aktif dengan `>` warna |
| `description`| `ReactNode` | —       | Teks penjelas dalam kurung di kanan  |
| `className`  | `string`    | —       | Kelas tambahan                       |

### SuccessProcess

| Prop       | Tipe        | Default | Deskripsi                    |
| ---------- | ----------- | ------- | ---------------------------- |
| `message`  | `string`    | —       | Teks pesan sukses (wajib)    |
| `className`| `string`    | —       | Kelas tambahan               |

### Result

| Prop       | Tipe        | Default | Deskripsi                    |
| ---------- | ----------- | ------- | ---------------------------- |
| `message`  | `string`    | —       | Teks output perintah (wajib) |
| `className`| `string`    | —       | Kelas tambahan               |

### Process

| Prop        | Tipe             | Default         | Deskripsi                                      |
| ----------- | ---------------- | --------------- | ---------------------------------------------- |
| `duration`  | `number`         | `3`             | Lama animasi dalam detik                       |
| `animation` | `ProcessAnimation` | `"progressBar"` | `"progressBar"`, `"spinner"`, atau `"none"`    |
| `label`     | `string`         | `"Processing"`  | Label di samping persentase                    |

  )

## 3. Cara Kerja

1. `TerminalView` menggambar jendela terminal — header dengan titik lampu (merah, kuning, hijau) dan judul `title`, lalu area konten monospace.
2. Semua komponen (`Command`, `Result`, `QuestionStep`, `Option`, `SuccessProcess`) menggunakan struktur yang sama: `flex items-center gap-2` dengan icon `w-4 text-center` sehingga sejajar.
3. `Result` menampilkan teks output perintah dengan warna abu-abu — cocok untuk menampilkan hasil instalasi atau pesan informasi.
4. `QuestionStep` menampilkan glyph `?` secara default, atau ceklis `✔` kuning jika `done={true}`. Anak `QuestionStep` di-indent ke kanan.
5. `Option` menampilkan `>` berwarna cyan jika `selected`, atau `>` transparan jika tidak — teks tetap sejajar.
6. `Process` menghitung kemajuan berbasis waktu (`duration` dalam detik) lewat `setInterval`, dan menghormati `prefers-reduced-motion`.
7. Warna terminal selalu gelap di kedua tema (light/dark) agar terlihat seperti jendela terminal sungguhan.

---

## 4. Catatan

- `TerminalView` adalah client component (berisi animasi `Process` yang bergantung pada `window`).
- `Process` secara otomatis berhenti dan menghormati preferensi gerakan yang dikurangi.
- Semua komponen tersedia di dalam evaluasi `ComponentPreview` — `import { TerminalView, ... } from "noxkit/common/terminal-view"` bisa dipakai.
