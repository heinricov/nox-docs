---
title: "TerminalView"
description: "Menampilkan cuplikan interaksi CLI bergaya jendela terminal di dalam dokumentasi."
---

`TerminalView` membungkus **cuplikan interaksi CLI** dalam kartu bergaya jendela terminal — lengkap dengan titik lampu macOS, judul, latar gelap, dan font monospace. Cocok untuk mendokumentasikan alur perintah CLI seperti `squad add`, hasil eksekusi, hingga proses berjalan.

Komponen penyusunnya bersifat komposisional: `Command` untuk perintah yang diketik, `ResultsProcess` untuk hasil eksekusi, `TerminalStep` untuk langkah, `Question`/`Option` untuk menu pilihan, `Process` untuk progres, serta `Done`/`Cancelled` untuk status akhir.

## Import

Di file MDX, `TerminalView` dan seluruh komponen penyusunnya sudah terdaftar otomatis di `MdxRenderer` — langsung bisa dipakai tanpa import.

Di file React/TSX, import terlebih dahulu:

<CodeBlock inline>
  ```tsx import { TerminalView, Command, ResultsProcess } from "mdxui" ```
</CodeBlock>

## Daftar komponen

| Komponen           | Fungsi                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------ |
| `TerminalView`     | Bungkus utama — jendela terminal dengan judul dan titik lampu                              |
| `Command`          | Baris perintah dengan glyph status (`❯`)                                                    |
| `ResultsProcess`   | Blok hasil eksekusi dengan garis samping; `status="error"` memberi warna merah              |
| `TerminalStep`     | Satu langkah interaksi dengan glyph sesuai `status`                                         |
| `AsciiArt`         | Menampilkan ASCII art berwarna cyan                                                         |
| `Question`         | Pertanyaan interaktif dengan glyph `◇`                                                       |
| `Option`           | Pilihan menu; `selected` memberi tanda `▣` + warna aktif                                    |
| `Prompt`           | Baris prompt sederhana dengan warna (`cyan`, `green`, `red`, `blue`)                        |
| `Process`          | Progres berjalan (`progressBar`/`ProgresBar`) dengan label dan persentase                    |
| `Done`             | Status sukses hijau `✔`                                                                     |
| `Cancelled`        | Status batal merah `■`                                                                      |

## Props

### TerminalView

| Prop       | Tipe        | Default      | Deskripsi                                  |
| ---------- | ----------- | ------------ | ------------------------------------------ |
| `title`    | `string`    | `"terminal"` | Teks judul di bar header jendela           |
| `className`| `string`    | —            | Kelas tambahan untuk menyesuaikan tampilan |
| `children` | `ReactNode` | —            | Konten di dalam jendela terminal (wajib)   |

### Command

| Prop       | Tipe         | Default   | Deskripsi                               |
| ---------- | ------------ | --------- | --------------------------------------- |
| `children` | `ReactNode`  | —         | Teks perintah (wajib)                   |
| `status`   | `Status`     | `command` | Warna glyph — `command`, `success`, `question`, `error`, `info`, `active` |

### ResultsProcess

| Prop       | Tipe         | Default   | Deskripsi                              |
| ---------- | ------------ | --------- | -------------------------------------- |
| `children` | `ReactNode`  | —         | Isi hasil eksekusi (wajib)             |
| `status`   | `Status`     | `active`  | `error` memberi warna garis samping merah |

### TerminalStep

| Prop       | Tipe         | Default | Deskripsi                         |
| ---------- | ------------ | ------- | --------------------------------- |
| `children` | `ReactNode`  | —       | Teks langkah (wajib)              |
| `status`   | `Status`     | `info`  | Warna glyph langkah               |

### Option

| Prop         | Tipe        | Default  | Deskripsi                            |
| ------------ | ----------- | -------- | ------------------------------------ |
| `children`   | `ReactNode` | —        | Nama pilihan (wajib)                 |
| `selected`   | `boolean`   | `false`  | Tandai pilihan aktif (`▣`, warna penuh) |
| `description`| `ReactNode` | —        | Teks penjelas dalam kurung di kanan  |

### Prompt

| Prop       | Tipe        | Default | Deskripsi                       |
| ---------- | ----------- | ------- | ------------------------------- |
| `children` | `ReactNode` | —       | Isi prompt (wajib)              |
| `color`    | `"cyan" \| "green" \| "red" \| "blue"` | `"cyan"` | Warna prompt |

### Process

| Prop        | Tipe    | Default         | Deskripsi                                                          |
| ----------- | ------- | --------------- | ------------------------------------------------------------------ |
| `duration`  | `number`| `3`             | Lama animasi dalam detik                                           |
| `animation` | `ProcessAnimation` | `"progressBar"` | `"progressBar"`, `"ProgresBar"`, `"spinner"`, atau `"none"` |
| `label`     | `string`| `"Processing"`  | Label di samping persentase                                        |

`Done`, `Cancelled`, `AsciiArt`, dan `Question` menerima `children` sebagai `ReactNode`.

## 3. Cara Kerja

1. `TerminalView` menggambar jendela terminal — header dengan titik lampu (cyan, biru, hijau) dan judul `title`, lalu area konten monospace.
2. Tiap komponen status (`Command`, `TerminalStep`, `Done`, `Cancelled`, dst.) memetakan prop `status` ke glyph dan warna `terminal-*` melalui CSS variabel (`--terminal-cyan`, `--terminal-green`, `--terminal-red`, dll.).
3. `Process` menghitung kemajuan berbasis waktu (`duration` dalam detik) lewat `setInterval`, dan menghormati `prefers-reduced-motion` dengan langsung menampilkan 100%.
4. `ResultsProcess` memberi garis samping (`border-l`) sebagai pembatas antara baris perintah dan hasil; `status="error"` menukar warnanya menjadi merah.
5. Warna terminal selalu gelap di kedua tema (light/dark) agar terlihat seperti jendela terminal sungguhan.

---

## 4. Catatan

- `TerminalView` adalah client component (berisi animasi `Process` yang bergantung pada `window`).
- `Process` secara otomatis berhenti dan menghormati preferensi gerakan yang dikurangi.
- Kelas warna `terminal-cyan`, `terminal-green`, `terminal-red`, dan `terminal-blue` juga tersedia sebagai utilitas teks untuk konten di dalam terminal — misalnya `<span className="terminal-cyan">squad add</span>`.
- Semua komponen tersedia di dalam evaluasi `ComponentPreview` — `import { TerminalView, ... } from "mdxui"` bisa dipakai.
