title: "PackageManagerTabs"
description: "Komponen untuk menampilkan perintah instalasi paket yang otomatis menyesuaikan dengan package manager (npm, pnpm, yarn, bun)"
---

`PackageManagerTabs` menampilkan perintah instalasi paket dalam kartu dengan dropdown untuk memilih package manager. Perintah otomatis diformat sesuai package manager yang dipilih — misalnya `npm install` menjadi `pnpm add` atau `yarn add`.

## Import

Di file MDX, `PackageManagerTabs` sudah terdaftar otomatis di `MdxRenderer` — langsung bisa dipakai tanpa import:

<CodeBlock filename="page.mdx">
```mdx
<PackageManagerTabs>shadcn@latest init</PackageManagerTabs>
```
</CodeBlock>

Di file React/TSX, import terlebih dahulu:

<CodeBlock inline>
```tsx
import { PackageManagerTabs } from "noxkit/common/package-manager-tabs"
```
</CodeBlock>

## Props

| Prop       | Tipe        | Default | Deskripsi                                    |
| ---------- | ----------- | ------- | -------------------------------------------- |
| `children` | `ReactNode` | —       | Teks perintah instalasi (wajib)              |
| `className`| `string`    | —       | Kelas tambahan untuk pembungkus              |
| `install`  | `boolean`   | `false` | Paksa gunakan `install`/`add` bukan runner   |
| `bash`     | `boolean`   | `false` | Mode bash — tanpa dropdown, tampilkan as-is  |

`children` harus berupa teks string berisi perintah yang ingin ditampilkan. Spasi di awal dan akhir akan diabaikan.

## Cara Kerja

Komponen ini menerima teks perintah mentah dan mengubahnya otomatis berdasarkan package manager yang dipilih:

### Mode bash

Ketika `bash={true}`:
- Dropdown package manager tidak ditampilkan
- Perintah ditampilkan apa adanya tanpa penambahan prefix (`npm install`, `npx`, dll)
- Label header berubah menjadi "bash"

### Aturan Format

| Kondisi | npm | pnpm | yarn | bun |
| ------- | --- | ---- | ---- | --- |
| Kata `init` di perintah | `npx ...` | `pnpm dlx ...` | `yarn dlx ...` | `bunx --bun ...` |
| Format `paket@versi` | `npx ...` | `pnpm dlx ...` | `yarn dlx ...` | `bunx --bun ...` |
| Perintah lainnya | `npm install ...` | `pnpm add ...` | `yarn add ...` | `bun add ...` |
| `install={true}` | `npm install ...` | `pnpm add ...` | `yarn add ...` | `bun add ...` |

### Contoh Konversi

| Perintah mentah | npm | pnpm | yarn | bun |
| --------------- | --- | ---- | ---- | --- |
| `zod` | `npm install zod` | `pnpm add zod` | `yarn add zod` | `bun add zod` |
| `react@18.3.1` | `npx react@18.3.1` | `pnpm dlx react@18.3.1` | `yarn dlx react@18.3.1` | `bunx --bun react@18.3.1` |
| `shadcn@latest init` | `npx shadcn@latest init` | `pnpm dlx shadcn@latest init` | `yarn dlx shadcn@latest init` | `bunx --bun shadcn@latest init` |

## Fitur

- **Dropdown package manager** — pilih antara npm, pnpm, yarn, atau bun
- **Salin perintah** — tombol clipboard untuk menyalin perintah yang sudah diformat
- **Deteksi `init` otomatis** — perintah dengan kata `init` menggunakan runner yang sesuai
- **Multi-baris** — bisa menampilkan beberapa perintah sekaligus dengan baris baru
- **Syntax highlighting** — runner abu-abu, paket cyan, flag amber
- **Mode bash** — tanpa dropdown, tampilkan perintah mentah

## 3. Catatan

- `PackageManagerTabs` adalah client component — gunakan langsung di file MDX tanpa memikirkan "use client".
- Teks `children` di-trim sebelum diproses, jadi spasi awal/akhir tidak mempengaruhi hasil.
- Pilihan package manager disimpan di state lokal (per komponen), bukan global.
- Setiap baris perintah mendapat prefix `$ ` otomatis.
- Mode `bash` cocok untuk perintah shell umum yang tidak terkait package manager.
