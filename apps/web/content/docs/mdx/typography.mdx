`mdxTypographyComponents` adalah kumpulan komponen React yang digunakan oleh `MdxRenderer` untuk merender konten MDX dengan gaya yang konsisten. Komponen ini sudah terdaftar otomatis — tidak perlu import manual di file MDX.

## Daftar Komponen

| Komponen     | Elemen HTML    | Deskripsi                                    |
| ------------ | -------------- | -------------------------------------------- |
| `h1`         | `<h1>`         | Heading level 1 — judul utama                |
| `h2`         | `<h2>`         | Heading level 2 — dengan auto-generated `id` |
| `h3`         | `<h3>`         | Heading level 3 — dengan auto-generated `id` |
| `h4`         | `<h4>`         | Heading level 4 — dengan auto-generated `id` |
| `p`          | `<p>`          | Paragraf                                     |
| `a`          | `<a>`          | Tautan dengan underline                      |
| `ul`         | `<ul>`         | Daftar tak berurutan (bullet)                |
| `ol`         | `<ol>`         | Daftar berurutan (angka)                     |
| `li`         | `<li>`         | Item daftar                                  |
| `code`       | `<code>`       | kode inline                                  |
| `pre`        | `<pre>`        | Blok kode                                    |
| `blockquote` | `<blockquote>` | Kutipan                                      |
| `strong`     | `<strong>`     | Teks tebal                                   |
| `hr`         | `<hr>`         | Garis pemisah horizontal                     |

## Gaya Default

### Heading

Heading memiliki margin atas yang berbeda untuk setiap level:

| Level | Class                          | Margin  |
| ----- | ------------------------------ | ------- |
| `h1`  | `mt-2 text-2xl font-bold`      | 0.5rem  |
| `h2`  | `mt-8 text-xl font-semibold`   | 2rem    |
| `h3`  | `mt-6 text-lg font-semibold`   | 1.5rem  |
| `h4`  | `mt-5 text-base font-semibold` | 1.25rem |

Contoh penggunaan heading:

```mdx
# Heading 1

## Heading 2

### Heading 3

#### Heading 4
```

Heading `h2`, `h3`, dan `h4` otomatis mendapat `id` dari konten teksnya (melalui `slugify`), sehingga bisa di-link langsung.

### Paragraf

Paragraf menggunakan ukuran font `15px` dengan line-height `relaxed` dan opacity `80%`.

```mdx
Paragraf menggunakan ukuran font `15px` dengan line-height `relaxed` dan opacity `80%`.
```

### Daftar

- `ul` dan `ol` memiliki `ml-4` (margin kiri) dan `space-y-1` antar item
- Marker list menggunakan warna `muted-foreground`

```mdx
- Item 1
- Item 2
- Item 3

1. Langkah 1
2. Langkah 2
3. Langkah 3
```

### Kode

- **Inline** (`code`): background `muted/50`, border, rounded, monospace `13px`
- **Block** (`pre`): border, background `background`, padding `4`, monospace `xs`

### Kutipan

Blockquote memiliki border kiri berwarna primary dan teks italic.

```mdx
> Ini adalah kutipan.
```

### Pemisah

`hr` memiliki margin atas dan bawah `my-2` (0.5rem).

```mdx
---

Bagian di atas dipisahkan dengan garis horizontal.
```

---

## 2. Cara Kerja

1. `MdxRenderer` mengimpor `mdxTypographyComponents` dan menggunakannya sebagai komponen bawaan untuk semua MDX content.
2. Heading `h2`-`h4` menggunakan `slugify()` untuk membuat `id` otomatis dari teks heading, memungkinkan direct linking.
3. Semua komponen menerima `children` sebagai `ReactNode`.
4. Gaya menggunakan Tailwind CSS dengan variabel tema (`foreground`, `primary`, `muted`, `border`).

---

## 3. Catatan

- Komponen ini sudah terdaftar otomatis di `MdxRenderer` — tidak perlu import di file MDX.
- Heading `h1` tidak mendapat `id` otomatis karena diasumsikan hanya satu per halaman.
- `slugify` mengubah teks menjadi URL-friendly (lowercase, spasi diganti `-`, special characters dihapus).
