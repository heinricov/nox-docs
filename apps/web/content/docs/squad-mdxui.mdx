# Squadra + MdxUI

**MdxUI** adalah library komponen MDX dari Squadra — kumpulan komponen untuk membangun situs dokumentasi: layout, navigasi sidebar, renderer MDX, table of contents, hingga komponen tampilan seperti `TerminalView`, `ProjectTree`, dan `CodeBlock`.

Halaman ini menjelaskan cara lengkap memakainya: dari memasang CLI, membuat proyek, menghubungkan `LayoutMain` di root layout, membuat route tangkap-semua (`[...docs]`), hingga menyusun file konten MDX beserta navigasinya.

## Persyaratan

- **Node.js** versi `20` atau lebih baru
- **pnpm** versi `10` atau lebih baru
- Git

## 1. Memasang CLI Squadra

Pasang package `squadra` secara global — perintahnya tersedia sebagai `squad`:

## 3. Perbarui Root Layout

Setelah proyek siap, impor `LayoutMain` dan `cn` dari `mdxui`, lalu bungkus seluruh halaman. `LayoutMain` menyediakan header, sidebar navigasi, dan layout responsif situs dokumentasi.

Buka `app/layout.tsx` dan perbarui dengan kode berikut:

<CodeBlock filename="app/layout.tsx">
  ```tsx
  import { Geist_Mono, Inter } from "next/font/google"

  import { cn, LayoutMain } from "mdxui"
  import { ThemeProvider } from "@/components/theme-provider"

  const inter = Inter({ subsets: ["latin"], variable: "--font-sans" })

  const fontMono = Geist_Mono({
    subsets: ["latin"],
    variable: "--font-mono",
  })

  export default function RootLayout({
    children,
  }: Readonly<{
    children: React.ReactNode
  }>) {
    return (
      <html
        lang="en"
        suppressHydrationWarning
        className={cn(
          "antialiased",
          fontMono.variable,
          "font-sans",
          inter.variable
        )}
      >
        <body>
          <ThemeProvider>
            <LayoutMain docsSet={["/docs"]}>{children}</LayoutMain>
          </ThemeProvider>
        </body>
      </html>
    )
  }
  ```
</CodeBlock>

Beberapa hal yang perlu diperhatikan:

- `ThemeProvider` adalah komponen dari proyek Anda (`@/components/theme-provider`) yang menyediakan tema light/dark — sudah ada bila proyek memakai `next-themes`.
- Prop `docsSet` menerima daftar prefix path yang diperlakukan sebagai halaman dokumentasi (sidebar tampil di path tersebut). Pada contoh di atas, `/docs` membuat halaman di bawah `/docs` menampilkan sidebar.
- `LayoutMain` mengimpor `mdxui/globals.css` secara otomatis, jadi tidak perlu mengimpor CSS tema secara manual.

## 4. Buat Route Tangkap-Semua `[...docs]`

Buat folder `app/[...docs]` — **nama folder wajib diapit tanda kurung siku dengan titik tiga `[...docs]`** agar menangkap semua segmen path di bawah `/docs`.

Di dalamnya buat file `page.tsx`:

<CodeBlock filename="app/[...docs]/page.tsx">
  ```tsx
  import { MdxLayout } from "mdxui"
  import {
    AlertNotice,
    DemoButton,
    GettingStartedCard,
    PlainNotice,
    ProfileCard,
  } from "@/examples"

  const mdxComponents = {
    AlertNotice,
    DemoButton,
    GettingStartedCard,
    PlainNotice,
    ProfileCard,
  }

  export default async function DocsPage({
    params,
  }: {
    params: Promise<{ docs?: string[] }>
  }) {
    const { docs = [] } = await params
    const segments = docs[0] === "docs" ? docs.slice(1) : docs

    return (
      <MdxLayout
        dir="/docs"
        slug={segments.join("/")}
        components={mdxComponents}
      />
    )
  }
  ```
</CodeBlock>

Penjelasan:

- `params.docs` berisi **array segmen path**. Misalnya `/docs/introduction` menghasilkan `docs = ["introduction"]`, dan `/docs/components/mdx/project-tree` menghasilkan `docs = ["components", "mdx", "project-tree"]`.
- Baris `docs[0] === "docs" ? docs.slice(1) : docs` menormalisasi path — segmen `docs` pertama dibuang agar `slug` cocok dengan struktur folder konten.
- `MdxLayout` menerima tiga prop:
  - `dir` — folder konten (wajib dimulai `/`), default `"/docs"`.
  - `slug` — jalur file MDX relatif terhadap `dir`, tanpa ekstensi.
  - `components` — komponen kustom (opsional) yang tersedia di dalam file MDX, selain komponen bawaan `mdxui` seperti `CodeBlock`, `TerminalView`, dan `ProjectTree` yang sudah otomatis terdaftar.

`MdxLayout` menghasilkan breadcrumb, header (judul + deskripsi + tanggal), isi halaman dari MDX, table of contents, dan navigasi prev/next.

## 5. Buat Folder `content` di Root

`mdxui` membaca konten dari folder `content` di root proyek Anda. Struktur folder di dalamnya **menjadi struktur navigasi sidebar** secara otomatis.

### 5.1 Struktur minimal

<ProjectTree name="my-docs">
  <Folder name="app" open>
    <Folder name="[...docs]" noted="Route tangkap-semua" />
    <File name="layout.tsx" noted="Root layout" />
  </Folder>
  <Folder name="content" open>
    <Folder name="docs" noted="Folder konten, jadi satu section sidebar" open>
      <File name="meta.ts" noted="Konfigurasi label, tipe & urutan" />
      <File name="introduction.mdx" />
      <File name="installation.mdx" />
      <File name="cli.mdx" />
    </Folder>
  </Folder>
  <File name="package.json" />
</ProjectTree>

### 5.2 Membuat file MDX

Setiap file `.mdx` di dalam `content` menjadi satu halaman. Tulis frontmatter di bagian atas untuk judul dan deskripsi:

<CodeBlock filename="content/docs/introduction.mdx">
  ```mdx
  ---
  title: "Introduction"
  description: "Mengenal Squadra dan mdxui"
  ---

  # Introduction

  Selamat datang di **Squadra**! Ini adalah konten pertama Anda.

  Komponen bawaan langsung tersedia, misalnya:

  <CodeBlock inline>
    ```bash squad list ```
  </CodeBlock>

  <TerminalView title="squad list">
    <Command>squad list</Command>
    <ResultsProcess>
      <Done>Semua perintah berhasil dimuat.</Done>
    </ResultsProcess>
  </TerminalView>
  ```
</CodeBlock>

Aturan penting:

- Setiap file MDX **wajib** punya frontmatter `title` (dipakai untuk judul header dan navigasi).
- Nama file tanpa ekstensi menentukan URL halaman. `content/docs/introduction.mdx` → `/docs/introduction`.
- Heading `##`, `###`, dan `####` di dalam file otomatis menjadi **table of contents** di sisi kanan.

### 5.3 Fungsi file `meta.ts`

Setiap folder konten bisa memiliki `meta.ts` untuk mengatur navigasi:

<CodeBlock filename="content/docs/meta.ts">
  ```ts
  ;({
    docs: {
      label: "Documentation",
      type: "main",
      order: ["introduction", "installation", "squad-mdxui", "cli"],
    },
  })
  ```
</CodeBlock>

| Field      | Tipe     | Deskripsi                                                                                |
| ---------- | -------- | ----------------------------------------------------------------------------------------- |
| `label`    | `string` | Nama yang tampil di sidebar untuk folder ini. Tanpa `label`, nama folder di-humanize.     |
| `type`     | `string` | `"main"` atau `"collaps"`. `main` menampilkan sub-folder sebagai bagian, `collaps` membuat header yang bisa dibuka/tutup. |
| `order`    | `string[]` | Urutan halaman di dalam folder. File yang tidak disebut akan ditampilkan setelahnya secara alfabetis. |

Pada contoh di atas, sidebar menampilkan section **Documentation** dengan urutan halaman `introduction`, `installation`, `squad-mdxui`, lalu `cli`.

### 5.4 Struktur yang ditangkap navigasi

Navigasi sidebar dibangun dari struktur folder secara rekursif:

- **Folder** di dalam `content` → satu **section** sidebar (labelnya dari `meta.ts` atau nama folder).
- **File `.mdx`** → item halaman di dalam section.
- **Sub-folder** → sub-menu; diatur oleh `type` pada `meta.ts` sub-folder tersebut:
  - `type: "main"` — item tampil sebagai bagian tetap.
  - `type: "collaps"` (default) — item tampil sebagai collapsible.
- **`index.mdx`** di dalam sub-folder → menjadi halaman pendaratan sub-folder tersebut (item mendapat `href`).
- `hidden: true` pada root `meta.ts` menyembunyikan folder dari navigasi.

Contoh struktur bersarang:

<ProjectTree name="content/docs">
  <Folder name="components" noted="Sub-folder jadi sub-menu" open>
    <File name="meta.ts" noted="type: collaps / main" />
    <Folder name="mdx" noted="Sub-sub-folder" open>
      <File name="meta.ts" />
      <File name="code-block.mdx" />
      <File name="terminal-view.mdx" />
    </Folder>
    <File name="button.mdx" />
  </Folder>
  <File name="introduction.mdx" />
</ProjectTree>

## 6. Menjalankan Proyek

Jalankan development server dari root proyek:

<CodeBlock filename="terminal">
  ```bash
  pnpm dev
  ```
</CodeBlock>

Buka `http://localhost:3000/docs/introduction` — jika halaman beserta sidebar dan table of contents muncul, semuanya sudah terhubung dengan benar.

## Penyelesaian Masalah

| Masalah                                  | Solusi                                                                |
| ---------------------------------------- | --------------------------------------------------------------------- |
| Halaman `404` saat membuka `/docs/...`   | Pastikan folder `app/[...docs]` menggunakan `[...docs]` (titik tiga) dan `content/docs` berisi file MDX |
| Sidebar tidak muncul                     | Pastikan `docsSet={["/docs"]}` di `LayoutMain` dan path sedang di bawah `/docs` |
| File MDX tidak tampil di navigasi        | Pastikan file memiliki frontmatter `title` dan nama folder berisi minimal satu file `.mdx` |
| Komponen kustom tidak dikenal            | Daftarkan komponen di `components` milik `MdxLayout` (misalnya lewat `mdxComponents`) |
